## 掲載文案

### このモデルに依頼したい。その後の流れをご案内します。

企画内容を伺い、本人の希望や日程、出演条件を確認しながら進めます。

1. **企画内容を相談**
   希望するモデルと、撮影の目的・内容をお知らせください。モデルが決まっていない場合も、企画のイメージからご相談いただけます。
2. **本人の希望・日程を確認**
   出演内容、日程、写真や映像の使い方などについて、本人の希望と対応できる範囲を確認します。
3. **見積もり・契約相手を確認**
   出演内容や使用範囲、費用の内訳を確認します。契約する相手と連絡窓口を明示したうえで、必要な条件を調整します。
4. **合意後に出演確定**
   関係者が内容と条件に合意したうえで出演を確定し、撮影・出演に進みます。

ご相談の段階では、出演は確定しません。本人の希望・日程や企画内容により、お受けできない場合があります。

### 合意の前に確認すること

- **契約相手・費用・支払条件**：契約する相手と窓口、出演料、調整料・交通費などの有無と内訳、支払条件を事前に確認します。
- **写真・動画の使用範囲**：使用媒体、掲載・使用期間、使用する地域、二次利用、競合に関する条件を確認します。追加利用する場合の扱いも確認します。
- **変更・延期・中止の条件**：内容や日程を変更する場合の連絡方法、延期・中止時の対応、費用が発生する条件を事前に確認します。

プロフィールの掲載は、個別の撮影・広告利用への承諾を意味しません。企画ごとに本人の意向と使用範囲を確認します。

### ご相談時に教えていただきたいこと

決まっている範囲でお知らせください。

| 項目 | 案内文 |
|---|---|
| 撮影の目的・内容 | 広告、商品撮影、映像作品など。企画の概要や希望するイメージ。 |
| 希望日時 | 撮影・出演の希望日、時間帯、予定している所要時間。 |
| 撮影・出演場所 | エリア、会場やスタジオ、屋内・屋外など。 |
| 使用媒体 | Webサイト、SNS、広告、印刷物など。使用する地域、二次利用の予定、競合に関する条件もお知らせください。 |
| 掲載・使用期間 | 掲載を始めたい時期と、写真や映像を使用する期間。 |
| ご予算 | 想定している予算や範囲。未定の場合は、その旨をお知らせください。 |

## 未確定のため掲載していない事項

- 契約当事者（依頼者・モデル・YOLO側のどの主体が契約するか）
- YOLOの役割（紹介・連絡調整・制作受託など）と責任範囲
- 手数料の有無、負担者、算定方法
- キャンセル・延期に関する条件と費用
- 請求先、支払先、支払時期、請求書等の発行主体
- 具体的な契約書式、利用許諾の範囲、追加利用時の手続き

これらは画面上で「決まっている条件」として案内していない。契約相手や費用・使用範囲・変更時の扱いは、合意前に確認する項目として示す。具体的な主体・金額・支払日・キャンセル率・代理権は記載しない。
相談が無料、掲載者が専属契約中、YOLOが当事者、日程仮押さえ済み、といった記述も入れない。
調査結果と運営判断が揃った後、必要な範囲だけ利用者向けの表現へ整える。

## 追加された事業意図と画面での扱い

ユーザーの意図は、YOLOでモデルの経験・成長を支え、外部の出演依頼につなぐ活動を目指すこと。
一覧の「モデル紹介」、既存の「活動の記録」、外部の「出演依頼」の順で構成する。
「これまでの活動」には公式サイトの既存の撮影会・映像制作等の紹介と活動記録へのリンクを置く。
モデル育成の実績として読み替えず、モデル個人の実績は本人の確認と掲載同意後に紹介する。
「これから目指すこと」は、成長支援・外部出演につなぐ体制づくりという将来方針として明示する。
育成カリキュラム、企業案件実績、所属人数、採用、雇用、専属、契約主体、報酬率は追加していない。
サイトで派遣・職業紹介のサービスを広告したり、許可不要と断定したりしない。
