これらはページの構成・表示を比較した観察であり、各社の成約率や操作性を測定したものではない。他社の文言・写真は転載せず、YOLOの制度や公開可能な事実を元に書き直した。

## 現状の課題

- 一覧の後に活動方針、将来像、依頼の4ステップ、確認条件、入力項目、相談面が続く。個別にもほぼ同じ説明が重なり、人物を見て依頼するまでの距離が長い。
- 「ブランド」という見出しに対し、実際の相談は写真・映像作品・広告・イベントにまたがる。本文は「目指す」といった運営側の方針が中心で、訪問者ができることが伝わりにくい。
- 一覧の英字名に比べて活動名が小さく、活動地域は詳細へ進まないと確認できない。
- 個別の最初のボタンは同じページの長い案内へスクロールするため、フォームへ進む操作がもう一段必要。
- フォームは連続した入力欄で、企画・使用予定・連絡先の区切りがない。

## 採用した文言・順序

一覧：短い紹介 → モデル一覧 → 出演相談 → YOLOの紹介・モデル応募。

- 見出し：「その人らしさが、企画の力になる。」
- 説明：「写真・映像・広告・イベント。YOLO公式モデルのプロフィールをご紹介します。」
- カード：写真 → 活動名 → 英字名 → 活動エリア → ジャンル・出演内容 → プロフィール。
- 出演相談：「モデルが決まっていなくても、企画からご相談ください。」
- YOLO紹介：熊本の制作・コミュニティ活動の事実と、既存の活動ページへのリンクを短く掲載。
- モデル応募：16歳以上・未経験可・審査制・16〜17歳の保護者同意を既存制度のまま案内。

個別：活動名と基本情報・写真 → 希望モデル付きの依頼フォーム → ギャラリー・掲載済み実績 → 短い相談面。

フォーム：「出演のご相談」。入力を「01 企画について／02 写真・映像の使用予定／03 ご連絡先」に分ける。未定の項目の書き方を最初に案内し、入力例・補足を必要な項目に付ける。詳しい相談の流れと、費用・支払条件・使用範囲・延期／中止の確認は折りたたみに集約した。

既存の本人プロフィール本文、写真、公開同意、権限、必須入力、重複防止・回数制限の条件は変更していない。実績や返信期限、対応地域、仕事の保証を追加していない。全フォーム項目と同意文は維持し、送信完了時は3つの入力グループをすべて無効化する。

## 確認

Nodeテスト10件、Chromeでの一覧・個別・導線・応募の14項目、受付フォーム6項目。PCと320〜1440pxの横はみ出しを確認。受付成功・失敗は模擬応答で、実送信は行わない。

架空4名の同じローカル表示で、一覧のページ高はPC1440px幅で3435→2167px、スマートフォン375px幅で5537→3179px。これは説明の重複を除いた結果であり、成約率・表示速度の評価ではない。フォームは入力欄自体を減らさず、グループ・補足を加えたため長さは短縮していない。

本番公開・DB変更はこのレビューに含めない。ソースを更新した後、現在開いているローカル確認画面も作り直す。
