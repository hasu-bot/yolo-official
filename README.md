# yolo-official

## YOLO SHOP

`/shop/` は Shopify Storefront Web Components を使った独立ページです。
商品・価格・在庫・注文・決済は Shopify が正本。管理 API の秘密鍵を公開サイトに埋め込まないでください。
Shopify ドメインは `ngtsfz-h8.myshopify.com`。商品が公開されると一覧に表示されます。
2026-10-22 時点で Shopify はトライアル中。ラストコールの3セットと共有在庫用の構成品を下書き登録済みです。販売条件の確認前は販売開始告知を行わないでください。
公式サイトの主要目的（LINE から YOLO 参加）を維持するため、ショップはトップページとは分離しています。

商品ID・共有在庫構成・公開前の具体的な確認項目は [販売準備・引き継ぎ](docs/shop-release.md) を参照してください。
